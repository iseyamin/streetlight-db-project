\# Smart Streetlight Fault Reporting \& Maintenance Analytics System



\## 📌 Project Description

This database project manages streetlight faults, maintenance teams, and repair tasks.



\## 🗂 Tables

\- USERS

\- STREETLIGHT

\- FAULT\_REPORT

\- MAINTENANCE\_TEAM

\- REPAIR\_TASK

\- MAINTENANCE\_LOG



\## ⚙️ Features

\- Fault reporting system

\- Task assignment

\- Maintenance tracking

\- Cost analytics



\## 🚀 How to Run

1\. Open phpMyAdmin

2\. Create database: streetlight\_management

3\. Import the .sql file
